SPATREN system design

Architecture of the fieldwork platform used by 70 L2S4 urban planning students on the Anuradhapura field visit: one React codebase shipped as a web app, an Android APK, and a desktop transcription workstation, backed by Supabase.

Web PWA · iOS + any browserAndroid APK · Capacitor 8Desktop · Tauri 2 (Win/Mac)Backend · SupabaseCost · free tier

01 · OverviewThree clients, one backend

The web app and the APK run the same React build. The APK wraps it in Capacitor and swaps a few browser APIs for native plugins (background GPS, notifications, file sharing, deep-link login, over-the-air updates). Everything a student collects is written to the phone first and uploaded later, so the app works with no signal. The desktop app is a separate Tauri program that receives interview recordings from phones as ZIP files and transcribes Sinhala audio locally.

Web app (PWA) Vite · React 18 · TS · Dexie · MapLibre · Workbox
  • iPhones (Home Screen app) and any browser
  • Hosted on Vercel at spatren.vercel.app
  • Service worker caches app, map tiles, fonts
  • Updates on next open
Android APK Capacitor 8 · lk.spatren.field · Gradle 9.1
  • Same web build inside a native shell
  • Background location as a foreground service
  • Native notifications, share sheet, file system
  • OTA web updates via self-hosted Capgo
SPATREN Desktop Tauri 2 · Rust · whisper.cpp · React
  • Imports recording ZIPs from phones
  • Sinhala speech-to-text, fully offline
  • Edit transcript against audio, export TXT/CSV
  • No login, nothing uploaded

One codebase: native.ts checks IS_NATIVE and routes to a Capacitor plugin or the browser API. Screens never branch on platform.

Server logic stays in Postgres: row-level security on every table, plus RPCs such as group_status, activity_between, claim_index and set_tracking. No custom server to run or pay for.

08 · Offline sync flowHow a record reaches the server

sequenceDiagram
  participant U as Student
  participant App as App (Web/APK)
  participant IDB as IndexedDB
  participant SB as Supabase
  participant Adm as Admin screen
  U->>App: Save survey / note / SOS
  App->>IDB: write record (synced = false)
  App-->>U: "Saved on this phone"
  loop every few seconds, and when signal returns
    App->>SB: upsert batch (client id, ignore duplicates)
    alt network OK
      SB-->>App: 201 confirmed
      App->>IDB: mark synced / delete outbox row
      SB-->>Adm: Realtime change event
    else offline or error
      App->>IDB: keep row, retry later
    end
  end

Upserts use client-generated ids, so retrying never creates duplicates, even if a confirmation was lost.

10 · SecurityControls in place

Access
  • Index login always requires a password, so one student can't open another's account
  • New members stay pending until an admin approves
  • Row-level security on every table; students see only their own records in Summary
Data
  • Interview audio never leaves the phone except as a ZIP the student sends
  • Storage accepts photos only, max 10 MB, approved users only
  • No API keys in the repo; Gemini keys live in the phone or in the settings table
Desktop
  • ZIP import blocks path-escape entries (zip-slip)
  • File access scoped to the app's library folder
  • Model file checked by its header before install
Release
  • APK signed with an RSA 4096 key kept off GitHub
  • OTA bundles verified by SHA-256 before applying
  • CSV exports neutralise spreadsheet formulas

11 · Desktop app buildWhat gets built next

Visual Studio Build Tools 2026 (18.11.3) is installed with the C++ compiler, CMake and Windows SDK 10.0.26100. Rust is installed but needs its default toolchain set. Build steps:

  1. Set the Rust toolchain (rustup default stable).
  2. Compile whisper.cpp v1.9.5 from source as a static whisper-cli.exe into desktop/src-tauri/bin.
  3. Make a smaller quantized copy of the Sinhala model (about 180–200 MB) and compare its accuracy with the full 488 MB model.
  4. Build and open SPATREN Desktop, add the model in Settings.
  5. Test end to end: import a ZIP exported from the APK, transcribe, edit, export TXT and CSV.
  6. Package the Windows installer; the Mac build runs on GitHub Actions.
